# WKConversions Brand Motion Profile

This file is a starting profile and should be updated when the official brand system is finalized.

## Position

WKConversions is a conversion-focused creative/performance business.

Desired impression:
- capable,
- modern,
- intentional,
- premium,
- performance-oriented,
- masculine without becoming aggressive,
- confident without becoming loud.

## Existing visual cue

Known dark brand background:
`#03111d`

Do not infer the full palette from this one color. Use official supplied brand assets when available.

## Motion personality

Default:
- precise,
- controlled,
- high-confidence,
- relatively fast,
- minimal gratuitous bounce,
- strong ease-outs,
- deliberate scale,
- clean transitions,
- occasional cinematic emphasis.

Avoid:
- childish elastic motion,
- overly playful sticker aesthetics,
- constant neon/glow,
- template-heavy corporate icon animation,
- generic "tech" particles unless conceptually justified.

## Brand-motion principle

WKC motion should suggest:
"designed to move" rather than "things moving everywhere."

Prefer one decisive visual transformation to five decorative animations.

## Update protocol

When official assets are supplied, add:
- logo clear-space rules,
- typefaces,
- type hierarchy,
- complete colors,
- corner-radius system,
- grid,
- UI treatment,
- image treatment,
- examples of approved motion,
- examples of rejected motion.
