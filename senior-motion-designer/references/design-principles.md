# Design Principles

## Purpose

Motion design begins with graphic design. Animation cannot rescue weak hierarchy, weak typography,
poor spacing, or an unclear concept.

## Visual hierarchy

A viewer should know what matters before consciously analyzing the frame.

Create hierarchy with:
- scale,
- weight,
- contrast,
- position,
- whitespace,
- depth,
- motion,
- lighting,
- focus,
- timing.

Do not make every element high contrast or large. Hierarchy requires difference.

## Focal point

Each important beat should have a primary focal point.

Ask:
- What should the viewer look at first?
- What should they notice second?
- What can remain peripheral?
- What can be removed?

Use motion to change the focal point over time.

## Reduction

Prefer the minimum number of elements necessary to communicate the idea.

Remove:
- redundant labels,
- decorative icons with no function,
- unnecessary shadows,
- meaningless particles,
- repeated copy,
- motion that does not alter attention or understanding.

## Contrast

Contrast can be created through:
- large/small,
- dense/empty,
- fast/slow,
- bright/dark,
- sharp/soft,
- still/moving,
- near/far,
- loud/quiet,
- complex/simple.

High-quality pacing uses contrast across time, not only within frames.

## Consistency versus repetition

Consistency means a coherent system.
Repetition means doing the exact same thing too often.

Maintain consistency in:
- typography system,
- corner radii,
- spacing logic,
- easing character,
- shape language,
- color logic,
- icon family,
- shadow/depth system.

Create variety in:
- framing,
- scale,
- scene density,
- animation tempo,
- object arrangement,
- visual metaphor,
- camera distance.

## Intentional imperfection

Perfect grids and centered layouts are not always premium.

Controlled asymmetry, crops, offsets, overlaps, partial reveals, and tension can make compositions
feel authored rather than templated.

The rule is intentionality, not symmetry.
