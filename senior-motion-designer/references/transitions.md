# Transitions

## Principle

The best transition is usually already present in the scene.

Ask:
"What existing object, edge, movement, scale relationship, or camera direction can produce the next scene?"

## Transition families

### Object continuity
An object remains visible while its role, scale, or environment changes.

### Match transformation
A shape, letter, interface component, or image transforms into a related form.

### Scale-through
Camera or object scale moves through an existing element into the next composition.

### Mask continuity
An existing edge becomes the reveal boundary.

### Layout transformation
Current elements rearrange into the next composition.

### Directional continuation
Motion exits in a direction and the next scene continues that vector.

### Foreground wipe
An existing foreground element crosses frame and conceals the cut.

### Focus/depth shift
Attention transfers between depth planes.

### Light/color transition
Use sparingly; visual property carries across scenes.

## Avoid

Avoid relying on:
- generic spin transitions,
- arbitrary zooms,
- random whip pans,
- repeated blur wipes,
- unnecessary glitch,
- transition packs with unrelated movement styles.

## Transition system

Choose a small family of transition behaviors for a video.

Examples:
- UI product film: layout transformation + scale-through + masks.
- cinematic brand piece: camera continuity + foreground wipes + match cuts.
- typography-led explainer: type scaling + shape morph + spatial continuation.

Consistency improves authorship.
