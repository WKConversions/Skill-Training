# Reference Analysis

## Goal

Extract design principles and motion grammar from reference work.

Do not summarize a reference as "clean, smooth, modern."

## Analyze in layers

### 1. Macro structure
Record:
- duration,
- hook,
- number of major beats,
- scene density,
- pace changes,
- climax,
- resolution.

### 2. Visual system
Record:
- typography,
- palette,
- geometry,
- image treatment,
- icon style,
- UI style,
- depth,
- texture,
- lighting.

### 3. Composition
For representative frames:
- focal point,
- alignment,
- negative space,
- scale hierarchy,
- crop,
- balance,
- depth planes.

### 4. Motion
For each important transition/action:
- start state,
- end state,
- duration estimate,
- direction,
- velocity character,
- easing character,
- overlap,
- anticipation,
- follow-through,
- secondary motion.

### 5. Continuity
Identify what carries across:
- object,
- direction,
- color,
- shape,
- camera,
- scale,
- texture,
- type.

### 6. Sound
Record:
- impacts,
- accents,
- ambience,
- transition sounds,
- music structure,
- silence.

### 7. Principle
For every notable technique answer:
"Why does this work?"

The answer must be transferable.

## Reference record format

Use:

REFERENCE:
TIMECODE:
COMMUNICATION PURPOSE:
STATIC COMPOSITION:
PRIMARY MOTION:
SECONDARY MOTION:
TRANSITION LOGIC:
TIMING:
EASING CHARACTER:
SOUND RELATION:
WHY IT WORKS:
TRANSFERABLE RULE:
DO NOT COPY:
