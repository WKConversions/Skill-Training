# Output Contract

Use this structure for a detailed motion-design production plan.

## Project direction

State:
- purpose,
- audience,
- format,
- duration,
- frame rate if known,
- core message,
- tone,
- art direction,
- motion personality,
- transition system.

## Scene table

For each scene provide:

### Scene [number] — [short name]
TIME:
VOICE-OVER:
COMMUNICATION GOAL:
VIEWER FOCUS:
VISUAL CONCEPT:
STATIC COMPOSITION:
ASSETS:
START STATE:
ANIMATION:
TIMING:
EASING:
SECONDARY MOTION:
CAMERA:
TRANSITION IN:
TRANSITION OUT:
SOUND:
AFTER EFFECTS NOTES:

## Animation precision

Use approximate numerical values where they improve reproducibility:
- frames,
- seconds,
- percentages,
- pixels where composition dimensions are known,
- degrees,
- blur amount,
- opacity,
- scale,
- delay.

Do not invent meaningless precision. Values are starting points to be visually tuned.

## Global consistency

End with:
- repeated motion rules,
- typography rules,
- transition rules,
- sound rules,
- exceptions,
- final QC targets.
