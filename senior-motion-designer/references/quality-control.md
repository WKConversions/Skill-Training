# Quality Control

## Pass 1 — Communication

- Can the viewer understand the idea?
- Does the visual support the spoken message?
- Is any scene too abstract?
- Is any scene merely illustrating nouns?

## Pass 2 — Static design

Pause on key frames.

Check:
- hierarchy,
- alignment,
- spacing,
- typography,
- color,
- negative space,
- focal point,
- crop,
- brand consistency.

If the paused frame looks weak, motion polish is not the priority.

## Pass 3 — Motion

Check:
- dominant motion,
- overlap,
- stagger logic,
- velocity,
- easing,
- anticipation,
- settle,
- motion blur,
- unnecessary movement.

## Pass 4 — Rhythm

Watch without stopping.

Check:
- monotony,
- rushed sections,
- dead sections,
- over-dense sections,
- lack of contrast,
- whether important ideas breathe.

## Pass 5 — Continuity

Check:
- visual connection between scenes,
- transition consistency,
- direction continuity,
- recurring motifs,
- whether scenes feel authored as one system.

## Pass 6 — Typography

Check:
- readability,
- line breaks,
- hold duration,
- over-animation,
- hierarchy,
- spelling.

## Pass 7 — Polish

Only now inspect:
- micro timing,
- subtle shadows,
- blur,
- textures,
- secondary animation,
- tiny alignment issues,
- edge cases.

## Red flags

The result is likely weak if:
- every scene uses the same entrance,
- every object bounces,
- every transition zooms,
- all copy is centered,
- every noun receives an icon,
- there is no pause,
- UI is shown at unreadable scale,
- scenes look like unrelated templates,
- sound effects are attached to every movement,
- effects compensate for poor layout.

## Final question

"What are the three changes that would most improve perceived professional quality?"

Make those changes before polishing low-impact details.
