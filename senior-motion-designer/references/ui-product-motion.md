# UI and Product Motion

## Goal

Product motion should make software understandable and desirable.

Do not merely pan around screenshots.

## Focus

Direct attention to one relevant interface action at a time.

Use:
- crop,
- zoom,
- spotlight contrast,
- depth,
- cursor/finger only when useful,
- component isolation,
- contextual labels,
- surrounding UI de-emphasis.

## Simplification

Rebuild or simplify interfaces when necessary for clarity, while preserving truthful product behavior.

Do not show ten UI details when the voice-over describes one feature.

## Interaction hierarchy

An interaction sequence often works as:
1. establish context,
2. identify actionable component,
3. trigger action,
4. show immediate response,
5. show outcome,
6. transition through the outcome.

## Cursor behavior

Avoid robotic cursor movement.

If used:
- give cursor a clear destination,
- use decisive motion,
- pause before important clicks if needed,
- synchronize click response tightly.

## Cards and panels

Cards should not all float independently.

Treat interfaces as connected systems.

Use layout changes, stack behavior, and shared containers to create continuity.

## Premium SaaS characteristics

Often:
- restrained overshoot,
- clean spatial hierarchy,
- crisp typography,
- controlled depth,
- short but not frantic interactions,
- deliberate spotlighting,
- consistent radius/shadow logic,
- minimal unnecessary rotation.
