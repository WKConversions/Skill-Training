# Composition and Hierarchy

## Grid

Use an underlying alignment system even when the final composition appears loose.

Establish:
- safe margins,
- major columns,
- baseline relationships,
- repeated alignment edges,
- spacing increments.

Break the grid deliberately, not accidentally.

## Centering

Do not center all copy and objects by default.

Use centered composition when it supports:
- symmetry,
- singular importance,
- logo/hero reveal,
- monumental scale,
- direct address.

Use offset/asymmetrical compositions for:
- movement,
- comparison,
- editorial sophistication,
- UI/product storytelling,
- directional flow.

## Negative space

Whitespace is active composition.

Leave room:
- around important type,
- in the direction an object moves,
- where the next object will enter,
- to create contrast against dense scenes.

## Scale

Scale is both hierarchy and storytelling.

Use dramatic scale difference intentionally.

Avoid a frame where all elements are medium-sized.

## Cropping

Objects may exceed frame boundaries when the crop communicates scale or creates energy.

Avoid accidental-looking tangencies:
- barely touching edges,
- text almost colliding,
- inconsistent near-crops.

## Depth

Depth can be implied using:
- scale,
- overlap,
- atmospheric blur,
- shadow,
- parallax,
- focus,
- z-position,
- lighting,
- perspective.

Use depth as a compositional tool, not as a feature checklist.
