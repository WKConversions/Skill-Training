# Motion Language

## Motion should have character

Define a motion personality before animating:
- precise,
- energetic,
- elegant,
- playful,
- technical,
- cinematic,
- mechanical,
- organic,
- aggressive,
- calm.

Every animation does not need the same curve, but it should feel like it belongs to the same world.

## Primary and secondary motion

Primary motion changes attention or meaning.

Secondary motion explains, supports, or adds physical response.

Example:
A card moves into focus = primary.
Its icon settles 3 frames later = secondary.

Do not let secondary motion become louder than primary motion.

## Choreography

Avoid simultaneous entrances unless intentionally creating an impact.

Useful sequence:
1. lead element initiates,
2. related elements follow with small offsets,
3. scene settles,
4. viewer reads,
5. next action begins.

## Anticipation

Use anticipation when it improves understanding or physical credibility.

Examples:
- object compresses before launch,
- camera subtly moves before a large push,
- mask edge appears before revealing content.

Do not add anticipation to tiny UI changes where it adds latency.

## Follow-through

Elements can finish at slightly different moments to avoid robotic motion.

Use subtle follow-through for:
- connected cards,
- typography groups,
- hanging/soft objects,
- linked UI components.

## Overshoot

Overshoot is a tool, not a default.

Use only when the motion personality and object behavior justify it.

Premium corporate/SaaS motion usually benefits from small controlled overshoot or none at all.

## Stagger

Stagger by meaningful groups.

Do not automatically stagger every letter, word, icon, and card.

Good stagger communicates:
- order,
- hierarchy,
- sequence,
- causality.

Random stagger creates noise.
