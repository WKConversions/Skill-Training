# Scripts

Use this directory for deterministic helper scripts as the skill matures.

Good candidates:
- extract evenly spaced frames from a reference video,
- generate contact sheets,
- inspect video duration/fps/resolution,
- validate project-brief fields,
- convert timecodes between fps values,
- create scene timing sheets,
- export reference thumbnails.

Prefer scripts for repeatable mechanical tasks. Keep taste and art direction in the reference guidance.
