# Video styles

The intake form offers three styles, each shown to the client as a reference image. A style defines
the look: materials, color logic, type, rendering, imagery and motion feel. It outranks any brand's
own site look, WKConversions' included; the brand supplies the accent color, the fonts, the logo and
the wording. The client's case and script decide everything else, including every scene's layout,
alignment and visual. In Karl's words: "I don't want to see the exact same alignments and visuals.
It has to suit the case and script."

The references are style references, never content or layout references (the difference is in
`references/reading-references.md`).

## Loading a style

Read only the chosen style's definition:
- `styles/minimal-user-interface.md`
- `styles/minimal-single-visual.md`
- `styles/minimal-gradient-saas.md`

Then view its contact sheet, `styles/<style>/sheet.jpg`, to calibrate the look. The sheet shows all
ten reference frames small, which is enough to read the look without inviting copies. Open a single
frame (`styles/<style>/01.jpg` to `10.jpg`) only to check a rendering detail such as a corner radius,
a glow or a type weight, never to borrow a layout. Never open another style's frames for the same
project, so the looks don't mix.

Every style keeps the motion craft (the moving camera, motion blur, overlapping builds;
`motion/animation-grammar.md`, `motion/camera.md`); the style sets its tempo.

## Copy check

Before the storyboard goes to Karl, compare every frame with the style's contact sheet. If a frame
shares a reference's composition or alignment, object, copy or data, redesign it until only the look
is shared.
